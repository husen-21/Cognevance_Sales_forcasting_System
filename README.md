# Sales Forecasting System

## 📌 Project Overview

The Sales Forecasting System is a data science and business intelligence project developed to analyze historical sales data and forecast future sales.

The project uses Python for data preprocessing, exploratory data analysis and machine learning, and Power BI for interactive dashboard visualization.

## 🎯 Objectives

- Analyze historical sales data
- Identify monthly and yearly sales trends
- Analyze sales by category and region
- Calculate moving average sales
- Build a Linear Regression forecasting model
- Forecast sales for the next 6 months
- Create an interactive Power BI dashboard

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook
- Power BI
- Excel
- GitHub

## 📊 Dataset

The project uses the SuperStore sales dataset containing information such as:

- Order Date
- Sales
- Quantity
- Discount
- Profit
- Category
- Sub-Category
- Region

## 🤖 Machine Learning Model

A Linear Regression model is used for sales forecasting.

The historical monthly sales data is converted into a time-series format using a time index. The model is trained using 80% of the historical data and evaluated using the remaining 20%.

### Evaluation Metrics

- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score

## 🔮 Future Forecast

The model predicts sales for the next 6 months based on historical sales trends.

## 📈 Power BI Dashboard

The dashboard contains:

- Total Sales
- Total Profit
- Total Quantity
- Monthly Sales Trend
- Sales by Category
- Sales by Region
- Moving Average Sales Trend
- 6-Month Sales Forecast
